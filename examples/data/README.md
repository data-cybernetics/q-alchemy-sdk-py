# Sparse molecular CISD targets

## LiH/STO-3G notebook target

`lih_sto3g_cisd.npz` is a numeric-only copy of the normalized lithium hydride
state generated by `qtucker-examples/ibm_experiment/1-qasm_generation.ipynb`
and saved as `sparse_vectors/lih.sparse_triplet.npz`.

- Geometry: `Li 0 0 0; H 0 0 1.60`, Angstrom.
- Basis: STO-3G; charge 0; spin 0; RHF / RCISD.
- Six spatial orbitals, twelve qubits, 35 nonzero amplitudes.
- The original determinant index ordering and amplitudes are preserved;
  no bit reversal or orbital reordering is applied.
- Norm squared: 1.0 within floating-point precision.

The archive contains `indices` (uint64), `amplitudes` (float64), and `num_qubits`
(integer scalar), with no pickled metadata. Load with
`numpy.load(path, allow_pickle=False)`.

`quantum_io_lih_reconstruction.ipynb` uses this smaller target for ideal, noisy,
and QPU acquisition. Its noisy mode imports the historical Almaden calibration
but keeps errors and connectivity only on qubits 0–11; both compilation and
simulation are bounded to twelve qubits. The saved LiH experiment's two-qubit
blocks, rank one, 95 training observables, and four AdamW fitting restarts of
600 epochs are retained. Preparation, observable generation, and fitting settings
match the original LiH configuration files. Compression remains enabled by
default; disable it to compare with the original uncompressed baseline.

## CO/STO-3G reference target

`co_sto3g_cisd.npz` is a numeric-only copy of the normalized carbon monoxide
state generated by `qtucker-examples/ibm_experiment/1-qasm_generation.ipynb`
and saved as `sparse_vectors/co.sparse_triplet.npz`.

- Geometry: `C 0 0 0; O 0 0 1.128`, Angstrom.
- Basis: STO-3G; charge 0; spin 0; RHF / RCISD.
- Ten spatial orbitals, twenty qubits, 288 nonzero amplitudes.
- Original determinant filtering tolerance: 1e-15; amplitude cutoff: 1e-12.
- The original notebook's interleaved determinant index ordering is preserved
  unchanged. No bit reversal or orbital reordering is applied here.
- Norm squared: 1.0 within floating-point precision.

The archive stores `indices` (uint64), `amplitudes` (float64), and `num_qubits`
(integer scalar). It contains no pickled objects or machine-specific paths.
Load with `numpy.load(path, allow_pickle=False)`.

This fixed reference was used by the original 20-qubit SDK notebook to reproduce the molecular input
without requiring PySCF, private QTucker libraries, or the original repository.
The exported reconstruction is a separate, potentially unnormalized subset of
an implicit fitted model; it must not be confused with this normalized input.
