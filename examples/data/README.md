# CO/STO-3G sparse CISD target

`co_sto3g_cisd.npz` is a numeric-only copy of the normalized carbon monoxide
state generated by `qtucker-examples/ibm_experiment/1-qasm_generation.ipynb`
and saved as `sparse_vectors/co.sparse_triplet.npz`.

- Geometry: `C 0 0 0; O 0 0 1.128`, Angstrom.
- Basis: STO-3G; charge 0; spin 0; RHF / RCISD.
- Ten spatial orbitals, twenty qubits, 288 nonzero amplitudes.
- Original determinant filtering tolerance: 1e-15; amplitude cutoff: 1e-12.
- The original notebook's interleaved determinant index ordering is preserved
  unchanged. No bit reversal or orbital reordering is applied here.
- Norm squared: 1.0 within floating-point precision.

The archive stores `indices` (uint64), `amplitudes` (float64), and `num_qubits`
(integer scalar). It contains no pickled objects or machine-specific paths.
Load with `numpy.load(path, allow_pickle=False)`.

The SDK notebook uses this fixed reference to reproduce the molecular input
without requiring PySCF, private QTucker libraries, or the original repository.
The exported reconstruction is a separate, potentially unnormalized subset of
an implicit fitted model; it must not be confused with this normalized input.
